# Graph Color Propagation

> **[English Documentation](README.md)**

グラフビューのノードの色を、リンク関係に基づいて未着色のノードに伝播させる Obsidian プラグインです。

Obsidian 標準の **グラフビュー → グループ** パネルで色グループを定義するだけで、そのグループに属さないノートにもリンク距離に応じた色が自動的に広がります。追加の設定ファイルやクエリ記法を覚える必要はありません。

## 機能

- **色の自動伝播** — グループに属さないノートは、リンクで繋がった色付きノートから距離（ホップ数）に応じてブレンドされた色を継承します。
- **グラフビュー設定とのリアルタイム同期** — グラフビュー設定で色グループを追加・変更・削除すると、プラグインが即座に検知して色を再適用します。ボタン操作は不要です。
- **伝播パラメータの調整** — 減衰係数・最大ホップ数・最小影響度の設定で、色がどこまで・どれくらいの強さで広がるかを制御できます。
- **手動操作** — リボンアイコン、コマンドパレット、設定画面の「Apply now」ボタンから、いつでも手動で色を再計算できます。

## 仕組み

1. グラフビュー設定（**設定 → グラフビュー → グループ**）で定義された色グループを読み取ります。`path:` と `tag:` クエリに対応しています。
2. ノート間のリンク（`[[ウィキリンク]]`）を元にグラフを構築します。
3. グループに属さない各ノートについて、幅優先探索（BFS）で最も近い色付きノートを **最大ホップ数** まで探索します。
4. 見つかった各色付きノートは `減衰係数 ^ ホップ距離` の重みで貢献します。**最小影響度** 以下の貢献は無視されます。
5. 重み付き平均色が、開いているグラフビューのノードに直接適用されます。

## 設定

| 設定項目 | 説明 | デフォルト |
|---|---|---|
| Auto-apply on graph open | グラフビューを開いた時やグループ設定変更時に自動で色を適用 | オン |
| Decay factor | 1ホップごとに色の影響力に掛ける係数（0〜1）。小さいほど遠くの色の影響が弱くなる | 0.6 |
| Max hops | 色付きノードを探索するホップ数の上限 | 3 |
| Min influence | この値以下の重みを持つ色は無視される | 0.05 |

## コマンド

- **Apply propagated colors to graph** — 色を手動で再計算し適用します。
- **Debug: Dump node structure to console** — 最初のグラフノードの内部構造を開発者コンソールに出力します。Obsidian のグラフレンダラー内部が変更された際のトラブルシューティング用です。

## 動作要件

- デスクトップ版のみ対応。グラフビューレンダラーの内部APIに依存しているため、モバイル版では利用できません。

## インストール

### コミュニティプラグインから（公開後）
1. **設定 → コミュニティプラグイン → 閲覧** を開く。
2. 「Graph Color Propagation」を検索。
3. **インストール** → **有効化** をクリック。

### 手動インストール
1. [最新リリース](../../releases) から `main.js` と `manifest.json` をダウンロード。
2. `<あなたのVault>/.obsidian/plugins/graph-color-propagation/` にコピー。
3. Obsidian を再起動し、**設定 → コミュニティプラグイン** でプラグインを有効化。

## 補足

- このプラグインは独自のグループ/クエリ UI を持ちません。色グループの管理はすべて Obsidian 標準のグラフビュー設定で行います。
- 伝播された色はリアルタイムで再計算されますが、`graph.json` には書き戻されません。グラフビューの表示にのみ影響します。
